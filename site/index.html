The essentials

Your text stays in your hands

TextAid works with the text you select and gives you a chance to check every result.

Choose

Pick an action

Press Ctrl+C, then C to open TextAid with a selection or an empty input area. Correct, rewrite, summarize, or choose another action.

Translate

Move quickly

Press Ctrl+C, then T to start a translation immediately. Review it and adjust the destination language when needed.

Review

Decide what to keep

Inspect the result, then copy it, replace the original selection when available, or cancel.

Connection choice

Use AI where it makes sense for you

TextAid uses a local Ollama model by default. You can deliberately configure an Ollama server on an administered network or an external OpenAI-compatible service for an action.

How connections and profiles work

This device only

Run a model through Ollama on your Windows computer.

On-premises

Connect to an Ollama server on a network you administer.

External

Use an explicitly configured OpenAI-compatible service.
